# Acceptance criteria

These are proposed release gates. The [evidence ledger](evidence.md) records the measurements available today.

| ID | Exercise | Passing observation |
|---|---|---|
| A1 — inference and streaming | Run 10 warm and 3 cold turns with a pinned local model through both interactive and headless entry points. Use a long response. | Record first content delta and completion at provider and client. Multiple native deltas arrive before completion. Joined deltas match the final text. Publish median and p95 time to first token with hardware and model. |
| A2 — abort, timeout and failover | Cancel during HTTP streaming and during a child process with a grandchild. Interrupt the primary provider before the first delta and again after partial output. | In 10 repetitions per case, exactly one terminal event, no new output after termination, and zero surviving fixture processes within five seconds. Policy determines fallback, local-only runs make zero remote requests, and resumed output contains no duplicated prefix. |
| A3 — automation output | Pipe the same task through JSON and JSONL consumers for success, rejection, timeout and cancellation. | JSON parses as one result. Every JSONL stdout line parses with sequential IDs and one terminal result. Diagnostic output stays on stderr. Published exit codes match outcomes. |
| A4 — terminal | Paste and edit a three-line Unicode prompt, attach a file and folder, inspect code and a diff, accept and reject a tool, restart and restore at 80 and 120 columns. | Text round-trips, activity matches actual tool output, rejection runs zero tools, restored history matches the settled transcript. Show provider-reported token usage and label estimates and unavailable costs. |
| A5 — browser and research | Navigate a controlled site through LiTT, extract a document, follow a citation, click/type/scroll, capture a screenshot, pause for takeover, resume, download into an approved directory and close. | URL and artifact match observed operations. Human takeover suspends automated input. Unauthorized download is denied. A failed action produces no success or fabricated citation. |
| A6 — autonomous coding and computer use | Complete a two-file fixture under a worktree lease, run a regression, interrupt and resume. Exercise a failed check, denied app action and bounded delegated read. | Regression fails before and passes after the fix, failed validation restores original bytes, unrelated files retain their hashes, delegate stays within its grant and final result cites command exits. |
| A7 — shared host | Submit the same permitted and denied requests through CLI, Chat, Studio and PocketOS. Resume a conversation on another authorized surface, then disconnect its transport. | Same policy decision for each client, zero denied side effects, coherent run IDs and context, explicit transport failure. Media/sandbox capability availability matches the selected host. |
| A8 — memory and triggers | Store a scoped fact, retrieve after restart, delete and retrieve again. Deliver a scheduled trigger and duplicate webhook before and after a crash. | Fact is accessible only in scope and disappears after deletion. One job per trigger identity, one terminal result, bounded retries and observable exit reason. |
| A9 — platform/resource | On Windows, native Linux, WSL and physical Termux, capture 20 startup samples, idle CPU/RSS for five minutes, concurrency and post-cancel process counts. Run offline and with PC inference available. | Publish platform results separately with versions. Concurrency never exceeds configuration, all fixture processes exit, Android records zero unsolicited model-daemon starts. Low-power and thermal modes reduce work at configured thresholds. Compare repeat measurements with the reviewed hardware baseline. |
