# LiTTree Product Vision

> **Build it in minutes. Understand it as you go. Take it anywhere.**

## Why LiTTree exists

AI site builders (Bolt, Lovable, v0, Replit Agent) prove that going from a prompt to working software in ~10 minutes is solved. That is no longer the differentiator.

The gap is everything **after** the first generation:

- Users don't understand what was built
- Users can't verify claims the AI makes
- Users lose context when switching tools
- Users outgrow the platform and hit a wall
- The experience is clinical, not memorable

LiTTree closes that gap.

## The product promise

**Fast like an AI builder. Fun like a creative playground. Reliable like a real development environment. Educational without feeling like school.**

## 5 Pillars

### 1. ⚡ Build Fast

```
Idea → LiTT understands → Plan → Build → Preview → Change → Verify → Publish
```

Target: first useful preview in **2–5 minutes** for a simple website.

No setup screens. No framework selection. No environment variables. No GitHub on day one.

The user describes their business. LiTT asks 2–3 useful questions. LiTT builds. Preview opens.

### 2. 🧠 Understand While Building

Progressive disclosure — same project, different complexity:

```
Beginner sees:                    Advanced user sees:
─────────────                     ──────────────────
Page                              DOM
Text                              React
Image                             Git
Button                            Branches
Style                             APIs
Publish                           Database
                                  CI
                                  Terminal
```

The user is never forced through programming school before they can make something. They learn by doing, with optional "Teach Me" moments.

### 3. 🎨 Make It Fun

- LiTT is a character, not a chatbot — floating, reacting, celebrating
- Themes and wallpapers make the workspace theirs
- Missions replace tutorials
- Visual editing + voice + text in the same conversation
- Achievements unlock cosmetic rewards (themes, LiTT shells, wallpapers)
- Build completion gets a tiny celebration, not a silent log line

### 4. ✅ Prove What Happened

No fake "fixed" or "connected." Every claim has evidence.

```
BUILD RECEIPT

Task: Fix mobile navigation
Changes: 3 files
TypeScript   ✓ VERIFIED
Tests        ✓ VERIFIED (141)
Build        ✓ VERIFIED
Preview      ✓ VERIFIED
Mobile 390px ✓ VERIFIED
Production   ○ NOT CHECKED
Checkpoint   #183
```

This is the **trust differentiator**. See `TRUTH_LAYER.md`.

### 5. 🌐 LiTT Follows the User

One LiTT brain. Multiple surfaces:

```
Web Studio → Phone → Mobile → VS Code/Windsurf → back to Studio
```

The surface changes, not the brain. Conversation, project, memory, and tools are canonical and portable.

See `LITT_CORE_ARCHITECTURE.md` and `PROJECT_PORTABILITY.md`.

## Positioning

### Not this

> "Another AI site builder that's 12 seconds faster."

### This

> **Bring the idea. Leave with something real.**

Build websites, apps, music, art and brands with an AI crew that remembers your project, shows its work, and teaches you as you go.

## The product ladder

```
BEGINNER
   ↓
Quick Build (2–5 min preview)
   ↓
Guided Build (Teach Me moments)
   ↓
Visual Editing (Canvas + voice)
   ↓
Understanding (Explain Mode, receipts)
   ↓
Advanced Studio (Code, Terminal, Git, Deploy)
   ↓
Real Developer / Creator
```

LiTTree grows with the user. Nothing gets dumbed down — beginners just don't see all of it initially.

## Onboarding question

After signup, one question:

> **What do you want LiTT to help you become?**

```
🚀 I just want to build things      → Builder (simple interface)
🧠 I want to learn while building    → Learner (missions + explanations)
💻 I already develop                 → Developer (full Studio)
🎨 I'm mostly a creator              → Creator (media-first Studio)
```

Users can switch anytime. This controls initial complexity, not capability.

## Four worlds (organizational structure)

```
             LiTTree

     ⚡ BUILD       🎨 CREATE

     🧠 LEARN       🌎 SHARE
```

- **BUILD**: websites, apps, dashboards, tools, automation
- **CREATE**: images, music, video, branding, documents
- **LEARN**: missions, explain my project, teach me, challenges, skill progress
- **SHARE**: gallery, remix, community, projects, collaboration

Studio is underneath all of them. "All in one" now has structure.

## What we are NOT building right now

- Marketplace expansion
- Tons of additional agents
- Complex social feed
- More random generators
- Deep mobile functionality
- Giant theme marketplace
- Fancy gamification economy
- Dozens of integrations

They can come. Right now they dilute the breakthrough.
