# LiTT Arcade — Cover Art Generation Prompts

> **Goal:** Generate unified, branded cover art for every game in the LiTT Arcade catalog.
> All covers should share the same art direction: dark neon background, LiTTree logo badge,
> circuit-tree aesthetic, and a single big game symbol in the center.

## Art Direction (applies to ALL covers)

**Style:** Dark cyberpunk arcade poster. Deep navy/black background (#08060F) with subtle
circuit-tree pattern. One bold game symbol centered. LiTTree logo (small, bottom-right corner).
Neon accent colors per game. Clean, premium, minimal — NOT cluttered.

**Dimensions:** 800x600 (4:3 aspect ratio), WebP format, < 100KB each.

**Common elements on every cover:**
- Background: #08060F with subtle radial glow in the game's accent color
- Center: One large, bold game symbol/icon (not a screenshot)
- Bottom-right: Small LiTTree circuit-tree logo (white, 40px, 60% opacity)
- Top-left: Small "LiTT" text badge (white, monospace, 12px)
- Bottom: Game brand title in bold sans-serif (white, 32px)
- Border: 2px inner border in accent color at 20% opacity

**DO NOT:**
- Use copyrighted character art (no actual Pac-Man, Mario, Sonic, etc.)
- Use screenshots from the games
- Use real game logos or trademarked fonts
- Add clutter or busy backgrounds

## How to Use These Prompts

### Option A: Midjourney / DALL-E / Stable Diffusion
1. Copy each prompt above
2. Generate at 800x600 (or 1024x768 then crop)
3. Save as WebP to `/public/games/artwork/{game-id}.webp`
4. Update `coverUrl` in `src/lib/games.ts` to point to `.webp`

### Option B: Figma / Canva Template
1. Create a master template (800x600, #08060F background)
2. Add the LiTTree logo as a locked layer (bottom-right, 40px, 60% opacity)
3. Add "LiTT" text badge (top-left, monospace, white)
4. For each game: add the center symbol, accent glow, and title
5. Export as WebP

### Option C: SVG Generator (programmatic)
Write a script that generates SVG covers with:
- Background rect (#08060F)
- Radial gradient glow (accent color)
- Game symbol (SVG path per game)
- LiTT logo (embed logo-littree.svg)
- Title text
Convert SVG to WebP with sharp.

## File Naming Convention

```
public/games/artwork/
  xquest.webp          ← XQuest
  pong.webp            ← Neon Paddle (keep same filename, new art)
  2048.webp            ← LiTT Merge
  hextris.webp         ← Hextris
  tetris.webp          ← Block Drop X
  pacman.webp          ← Maze Munch
  snake.webp           ← Byte Snake
  sudoku.webp          ← Number Grid
  flappy.webp          ← Pipe Hopper
  minesweeper.webp     ← Grid Sweep
  solitaire.webp       ← LiTT Solitaire (native)
  wordhunt.webp        ← Word Hunt (native)
```

Keep the same filenames so no code changes needed — just replace the PNG files
with WebP versions. Update `coverUrl` extensions from `.png` to `.webp` in
`src/lib/games.ts` when ready.
