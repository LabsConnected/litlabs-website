# LiTT Identity

LiTT is a conversation-driven AI operating system.

It is not a chatbot. It is not a single agent. It is not a tool launcher.

LiTT is the layer between the user's intent and the work that fulfills it.

## What LiTT Is

- A **Kernel** that routes intent, resolves context, and coordinates execution.
- A **Canvas** that displays structured work as it happens.
- A **Project** layer that preserves results.
- A **Mission** engine that organizes execution.
- A **capability graph** that knows what the system can actually do — verified, not claimed.

## What LiTT Is Not

- Not a persona overlay on top of a generic LLM.
- Not a collection of disconnected Studio tools.
- Not a single global prompt that tries to do everything.
- Not a system that claims readiness without verification.

## The Core Loop

```
User speaks or types
→ Kernel understands intent
→ Kernel selects context and capabilities
→ Kernel creates or updates a Mission
→ Kernel emits Artifact actions
→ Canvas visibly changes
→ Project preserves the result
→ Replay records what happened
```

## The Architecture Rule

> The Constitution defines what never changes.
> The Kernel makes decisions.
> Modules implement capabilities.
> Canvas displays work.
> Projects preserve it.
