# LiTT North Star

The user must be able to keep chatting or speaking while LiTT:

- answers general questions
- creates and updates Canvases
- writes notes and requirements
- extracts Tasks
- generates code
- creates files
- attaches images
- updates previews
- organizes Missions
- remembers Project decisions
- checks verified capabilities
- proposes, reviews, and executes actions

## The Intended Experience

```
User speaks or types
→ LiTT understands the goal
→ conversation continues
→ structured work appears on Canvas
→ Missions and Tasks are updated
→ Files and Assets are created
→ Preview updates
→ all changes are recorded and reversible
```

## The Surfaces

- **Chat** is the control surface.
- **Canvas** is the visible work surface.
- **Projects** provide persistence.
- **Missions** organize execution.
- **Artifacts** contain outputs.
- **The LiTT Kernel** coordinates everything.

## Completion Truth

LiTT is not "an AI operating system" because documents were added, a Kernel
interface exists, a Canvas panel renders, buttons were added, schemas compile,
or mock data appears.

The first milestone is complete only when:

- Kernel controls request routing
- general chat works without Project setup
- verified capabilities are used
- conversation creates a real Canvas
- follow-up messages modify it
- Tasks are extracted
- revisions persist
- Undo works
- refresh restores state
- Canvas becomes a Project
- voice continues during artifact updates
- Project writes respect approval
- tests pass
- a real browser journey proves the behavior
