fix: make all settings sections visible with mode unlocking

The settings page had 4 control modes (Standard → Advanced → Pro →
Owner) that gated which sections were visible. Users in Standard mode
could only see 7 sections — the other 7 (Voice & Camera, Performance,
Advanced, AI & Models, LiTT & Spark, Connections, Automation, System)
were completely invisible with no indication they existed.

Problems:
1. Mobile: ModeSelector was not rendered at all — just a static text
   label showing "Standard" with no way to change it
2. Desktop: ModeSelector was a tiny button in the corner, easy to miss
3. Both: Section lists only showed unlocked sections, so users had no
   idea that Advanced/Pro/Owner sections existed

Fix:
- Mobile header: replaced static "Standard" text with the interactive
  ModeSelector dropdown (same as desktop)
- Mobile section list: now shows ALL 15 sections. Locked sections are
  greyed out with a lock icon and a badge showing which mode unlocks
  them (e.g. "PRO"). Tapping a locked section switches to that mode.
- Desktop sidebar: same treatment — all sections visible, locked ones
  greyed out with lock icon and mode badge, click to switch mode
- Added a mode banner at the top of the mobile section list showing
  the current mode with a quick switch button
- When searching, only matching sections are shown (locked or not)
